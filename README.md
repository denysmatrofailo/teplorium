# Teplorium

Лендинг послуг утеплення пінополіуретаном (ППУ): утеплення, герметизація, ізоляція трубопроводів і вентиляції, звукоізоляція.

Чистий HTML/CSS/JS без залежностей. Для запуску достатньо відкрити `index.html` або залити файли на будь-який статичний хостинг (GitHub Pages, Netlify).

## Структура

- `index.html` — розмітка сторінки
- `css/styles.css` — стилі (mobile-first)
- `js/main.js` — 3D-стіна в hero, анімації, форма заявки
- `assets/img/` — логотип і фото

## Перед запуском

Форма заявки надсилає JSON `{ name, phone, topic, msg, page }` методом POST. Вкажіть адресу обробника (Formspree, Telegram-бот, власний бекенд) у константі `FORM_ENDPOINT` у `js/main.js`.
